# IT Change & Release Management Tracker

A lightweight web-based application for managing IT change requests, risk assessment, approvals, release readiness, and post-release reviews.

## Overview

The IT Change & Release Management Tracker provides a structured workflow for tracking changes throughout their lifecycle.

The application helps users:

- Create and manage IT change requests
- Assess change risk using impact and likelihood
- Track approval status
- Verify release readiness
- Maintain implementation and rollback plans
- Schedule planned changes
- Record post-release outcomes
- Capture issues and lessons learned
- Monitor change activity through a dashboard
